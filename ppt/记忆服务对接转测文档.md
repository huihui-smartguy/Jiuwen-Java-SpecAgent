# 需求转测试文档 - 记忆服务增强

| 项目    | 内容                            |

| 关联 MR | #78 (对接 Mem0), #90 (适配九问)     |
| 合入分支  | develop                       |
| 转测日期  | 2026-07-21                    |
| 转测人   | 研发                            |

***

## 一、需求概述

本次转测包含两个 MR 的合入内容，核心目标是增强 Agent Runtime Java 的长期记忆服务能力：

| MR          | 功能概述                                                                                      |
| ----------- | ----------------------------------------------------------------------------------------- |
| #78 对接 Mem0 | 对接 Mem0 云化版本，提供基础的记忆存储能力（add/search/get/delete），集成治理策略（超时/重试/熔断/审计）                       |
| #90 适配九问    | 1) Mem0 自部署增强（支持多种认证模式和路径风格）2) 引入 SPI 扩展机制（MemoryStoreProvider）3) 新增九问 Memory Engine 后端支持 |

***

## 二、测试范围

### 2.1 功能测试范围

| 序号 | 测试项                 | 优先级 | 说明                                           |

### 3.3 配置文件说明

**配置加载顺序**（后加载的覆盖先加载的）：

1. `application-base.yml` - 基础配置
2. `application-base_local.yml` - 本地覆盖（gitignored）
3. `application-memory.yml` - 记忆服务通用配置
4. `application-mem0.yml` 或 `application-jiuwen.yml` - Provider 配置

**切换到九问 Provider**：

修改 `application.yml` 中的 import：

```yaml
spring:
  config:
    import:
      - optional:classpath:application-base.yml
      - optional:classpath:application-memory.yml
      - optional:classpath:application-jiuwen.yml  # 替换 application-mem0.yml
```

**切换到 Mem0 Provider**：

```yaml
spring:
  config:
    import:
      - optional:classpath:application-base.yml
      - optional:classpath:application-memory.yml
      - optional:classpath:application-mem0.yml
```

### 3.4 启动命令

```powershell
# 编译
mvn clean package -DskipTests -pl service/agent-service-demo/example/memory -am

# 启动（使用九问）
java -jar service/agent-service-demo/example/memory/target/agent-service-demo-memory-0.1.0.jar

# 或通过环境变量指定
$env:JIUWEN_ENDPOINT="http://1.94.231.141:8516"
$env:JIUWEN_API_KEY="mem-key-2026"
$env:JIUWEN_USER_ID="demo-user"
java -jar service/agent-service-demo/example/memory/target/agent-service-demo-memory-0.1.0.jar
```

服务默认监听 `http://localhost:8094`

#### TC-002: 记忆写入与召回（非流式）

**前置条件**: 服务已启动，配置 provider=jiuwen

**步骤 1 - 写入记忆**:

```http
POST http://localhost:8094/v1/query
Content-Type: application/json

{
  "conversation_id": "tc-002-001",
  "message": "请记住：我喜欢喝手冲咖啡，不喜欢美式咖啡",
  "stream": false
}
```

**预期**: Agent 确认已记录偏好

**步骤 2 - 等待索引（3秒后）**:

```powershell
Start-Sleep -Seconds 3
```

**步骤 3 - 召回记忆（新会话）**:

```http
POST http://localhost:8094/v1/query
Content-Type: application/json

{
  "conversation_id": "tc-002-002",
  "message": "你还记得我喜欢喝什么咖啡吗？",
  "stream": false
}
```

**预期**: Agent 能正确回答"你喜欢手冲咖啡，不喜欢美式咖啡"

### 4.4 治理策略测试

#### TC-301: 超时处理

**前置条件**: 将 timeout-ms 设置为较小值（如 1000）

**步骤**:

1. 发送对话请求
2. 观察日志

**预期**:

- 若记忆服务响应慢，日志出现超时错误
- Agent 优雅降级，继续正常对话

***

#### TC-302: 重试机制

**配置**:

```yaml
retry:
  max: 2
  backoff-ms: 500
```

**预期**:

- 首次请求失败后，自动重试最多 2 次
- 每次重试间隔 500ms（指数退避）

***

#### TC-303: 熔断器

**配置**:

```yaml
circuit-breaker:
  enabled: true
  failure-threshold: 5
  reset-timeout-ms: 120000
```

**预期**:

- 连续失败 5 次后，熔断器打开
- 后续请求直接返回降级响应，不访问记忆服务
- 120 秒后熔断器半开，尝试恢复

***

#### TC-304: 审计日志

**预期日志格式**:

```
EXTERNAL_CALL_AUDIT adapter=Memory, success=true, target=http://1.94.231.141:8516, method=memory.add, attempt=1, elapsedMs=701
EXTERNAL_CALL_AUDIT adapter=Memory, success=true, target=http://1.94.231.141:8516, method=memory.search, attempt=1, elapsedMs=496
```

## 五、已知限制

| 项目            | 说明                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------- |
| 九问 delete 不支持 | 九问 Memory Engine API 不支持按 memory\_id 删除，调用 `delete()` 会抛出 `UnsupportedOperationException` |
| 九问 get 性能     | 九问无直接 get-by-id 接口，需分页遍历查找（最多 10 页 × 50 条）                                                |
| 记忆写入延迟        | 九问记忆写入后需等待 3-5 秒索引才能生效                                                                    |

***

## 六、验收标准

| 序号 | 验收项   | 标准                                |
| -- | ----- | --------------------------------- |
| 1  | 基础对话  | Agent 能正常响应问题                     |
| 2  | 记忆写入  | 能通过 memory\_add 工具或直接调用写入记忆       |
| 3  | 记忆召回  | 能在后续对话中正确召回历史记忆                   |
| 4  | 跨会话记忆 | 不同 conversation\_id 间能共享同一用户的记忆   |
| 5  | 优雅降级  | 记忆服务异常时，Agent 仍能正常对话              |
| 6  | 审计日志  | 所有记忆操作均有 EXTERNAL\_CALL\_AUDIT 日志 |
