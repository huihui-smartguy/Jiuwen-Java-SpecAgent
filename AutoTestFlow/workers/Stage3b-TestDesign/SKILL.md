# Stage3b-TestDesign

## Boundary

This Worker owns original Stage 3b test design. It converts enriched scenarios
into test cases using small-file mode and merges the batches into canonical
`TestCases` artifacts.

## Original Inputs

- `FeatureAnalysis/s3a_enriched_index.json`.
- `FeatureAnalysis/s3a_enriched/*.json`.
- `FeatureAnalysis/s3a_framework.json`.
- `Contract/contract.md`.
- `KnowledgeBase/fault_matches.json` when present.
- `QualityGates/professional_case_guidance.json` when present.
- `AutoTestFlow/templates/stage3b_batch_design.md`.
- `AutoTestFlow/shared/rules.md`.

## Original Mechanics

- Batch by scenario ids using the existing `--case-batch-size` behavior.
- Each batch reads only indexes, single scenario files, contract, and optional
  bounded guidance artifacts.
- Run `AutoTestFlow/scripts/merge_test_design.py`.
- Render test examples with existing deterministic Markdown rendering.

## Original Outputs

- `TestCases/test_design_batch_*.json`.
- `TestCases/test_design.json`.
- `TestCases/test_examples.md`.
- `TestCases/scene_tc_mapping.json`.
- `TestCases/e2e_scenes.json` when generated by the original flow.

## Gates

- Stage 3b human confirmation remains mandatory for FP mapping and assertion
  reasonableness. Existing conservative knowledge-backed downgrade behavior for
  limited coverage dimensions is preserved.

## Non-Goals

- Do not change assertion authority: executable assertions still require
  `Contract/contract.md`.
- Do not read or pass the full `test_design.json` into later case Workers.
